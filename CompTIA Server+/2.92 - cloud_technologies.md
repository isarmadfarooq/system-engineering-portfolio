## Cloud Technologies

### Objectives:

At the end of this episode, I will be able to:

1. Identify cloud technologies and components.

Exam Objective: *2.5 - Summarize the purpose and operation of virtualization.*

Description: In this episode, the viewer will identify the characteristics of the cloud. The viewer will also identify cloud service models as well as the cloud deployment models.

-----------------------------------------------------------

* Demonstrate and discuss key cloud characteristics.
	+ Log into the Azure Tenant
		-  On-demand self-service
	+ Log into Azure Mobile App
		-  Broad network access \(Laptop, smartphone,tablet)
	+ Create a Storage Account \(Resource Group, vNET)
		-  Resource pooling
	+ Create an Availability Set
		-  Rapid elasticity
	+ Show Cost Management
		-  Measured service
+ Compare and contrast cloud service models.
	+ View vNET
		-  Infrastructure as a Service \(IaaS\)
	+ TSearch for App Services and create/view offerings
		-  Platform as a Service \(PaaS\)
	+ Search for SaaS offerings in Azure
		-  Software as a Service \(SaaS\)
+ Compare and contrast deployment models
	+ Public cloud
	+ Private cloud
		- Virtual Private Cloud
	+ Hybrid cloud
	+ Community cloud
