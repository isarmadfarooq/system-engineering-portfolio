## Hardware Tools and Techniques

### Objectives:

At the end of this episode, I will be able to:

1. Identify tools and techniques to troubleshoot hardware failures.

Exam Objective: *4.2 - Given a scenario, troubleshoot common hardware failures.*   

Description: In this episode, the viewer will identify common component issue such as CPU, RAM, power and utilization as well as some of the tools and techniques performed to diagnose and resolve these issues.
