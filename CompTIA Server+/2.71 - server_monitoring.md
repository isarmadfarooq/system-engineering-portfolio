## Server Monitoring

### Objectives:

At the end of this episode, I will be able to:

1. Identify tools and techniques to perform server monitoring. Identify key attributes of event logs.

Exam Objective: *2.3 - Given a scenario, configure and maintain server functions and features.*

Description: In this episode, the viewer will identify tools and techniques to perform server monitoring and associated concepts like uptime, thresholds,  and performance metric such as memory, disk network and CPU utilization. The viewer will also identify different event log attributes such as alerting, reporting, retention and rotation.
