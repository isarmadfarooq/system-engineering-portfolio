## Server Network Configuration

### Objectives:

At the end of this episode, I will be able to:

1. Identify the appropriate network infrastructure service and server configuration, given a scenario.

Exam Objective: *2.2 - Given a scenario, configure servers to use network infrastructure services.*

Description: In this episode, the viewer will identify how to locate and configure server settings to use network infrastructure services such as DNS, IP addressing, firewall ports.

-----------------------------------------------------------

* MAC Address
	+ can be important for port security
	+ Most like configured inside a VLAN
*  IP configuration
	+ IPv4 and IPv6
	+ Static vs. dynamic \(DHCP\) vs. APIPA
	+ Utilities
		- Server Manager
		- Network and Sharing Center
		- Command line
		- Powershell
* Default Gateway
* DNS
	+ Configure hostname
	+ Configure DNS servers
	+ Internal vs. External
* Firewall
	+ Implict deny
	+ Network Location \(sets the firewall profile\)
	+ Outbound is open
	+ Inbound is block
	+ Think RDP and third party applications
		- Identifying ports and these services attached to those ports is important
