## Scripting Basics

### Objectives:

At the end of this episode, I will be able to:

1. Identify key concepts of server administration scripting.

Exam Objective: *2.6 - Summarize scripting basics for server administration.*

Description: In this episode, the viewer will identify the basic components used for scripting in server administration and various tasks that  can be associated with scripting.

--------------------------------------------------------

* Script types
	+ Bash
		- Shell scripts
		- Permissions
		- Text files
		- "#" comment syntax
		- printenv \(Environment Variables\)
		- Running Loops, discuss conditionals, comparator or compare operators
	+ Batch
		- Windows scripting file
		- Replaced by command files
		- "Rem" called Remarks
		- "::" called statements
		- Discuss integers, strings and arrays
	+ PowerShell
		- .ps files
		- Start Spooler service
	+ Virtual basic script (VBS)
* Common server administration scripting tasks
	+ Startup/Shut down/start up/shutdown
	+ Service \(demo with PS script\)
	+ Account creation
	+ Bootstrap
