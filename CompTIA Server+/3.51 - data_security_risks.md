## Data Security Risks

### Objectives:

At the end of this episode, I will be able to:

1. Identify data security risks.

Exam Objective: *3.4 - Explain data security risks and mitigation strategies.*

Description: In this episode, the viewer will identify various data security risks such as hardware failure, malware, data corruption theft, social engineering and data breaches.

-----------------------------------------------------------


* Component failure
	+ Storage device
		- Implement RAID solutions
		- Backup strategies
		- Is cloud storage a solution?
	+ RAID controller
		- Consider duplexing
		- Is cloud storage a solution?
	+ Power supply/circuit
		- Redundant power distribution techniques
	+ Data corruption
		- Integrity scanning
		- Checksums
		- Storage protection \(bit rot for archival data\)
		- Backups
	+ Common theme: Component redundancy and backups
* Theft
	+ Storage devices
		- Drive encryption
		- Drive locks \(think physical security\)
		- Server locks
	+ Laptops and mobile devices
	+ Malware
	+ Insider threats and backdoors
	+ Social engineering
* Breaches
	+ Identification & disclosure
	+ Unwanted duplication and/or publication
