## System Crashes and Lockups

### Objectives:

At the end of this episode, I will be able to:

1. Identify tools and techniques to troubleshoot hardware failures.

Exam Objective: *4.2 - Given a scenario, troubleshoot common hardware failures.*   

Description: In this episode, the viewer will identify system crashes as well as utilities such as event logs, Task Manager, Services consoles, dump files and Device Management.

-----------------------------------------------------------

+ System Crashes
	- Random (memory, overheating, application, driver\)
	- Persistant \(component failure, OS corruption\)
+ Crash screens
    - Blue screen
        * Windows General Protection Fault \(GPF\)
        * C:\Windows\minidump
        * Event Viewer > System > Filter Log > Error/Critical
    - Purple Screen
        * ESXi Hosts
        * VMWare Kernel
        * Close
    - Kernel Panic
        * Unix-like systems \(Linux/macOS\)
+ System lockups and hangs
	- Driver issues \(Device Manager\)
		* Missing
		* Corrupted
		* Incompatible
		* Incorrect
	- Improperly seating hardware components
