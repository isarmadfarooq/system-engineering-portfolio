## Data Migration and Transfer

### Objectives:

At the end of this episode, I will be able to:

1. Identify data migration and transfer techniques and tools.

Exam Objective: *2.3 - Given a scenario, configure and maintain server functions and features.*

Description: In this episode, the viewer will identify tools and techniques used in data migration and transfers such as infiltration, exfiltration, Robocopy, File Transfer Protocol, Secure FTP, FastCopy, and Secure Copy Protocol.

-----------------------------------------------------------

* Data migration and transfer
	+ Why migrate data?
		- Newly deployed server
		- Server maintenance or upgrades
		- Storage upgrade or maintenance
	+ Transfer utilities \(compatibility, security and performance\)
		- FTP, SFTP
		- Robocopy, xcopy, copy
		- cp, dd
		- WinSCP
		- SCP
		- FastCopy
	+ Migrate Windows user data
		- On filesrv02 create a new virtual disk with a volume called 
		backups"
		- Set permissions \(shared = full control; ntfs = r,w,x\)
		- Connect from filesrv02 to filesrv01 \(SMB\ via File Explorer)
		- On filesrv02 run SCP
		```
		scp -r administrator@10.10.10.150:e:\edutainers z:\backups
		```
	+ Confirm successful data migration
		```
		cd z:\backups
		dir
		```
