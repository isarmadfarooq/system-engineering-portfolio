## Security Issues and Tools

### Objectives:

At the end of this episode, I will be able to:

1. Identify common security issues.

Exam Objective: *4.6 - Given a scenario, troubleshoot security problems.*   

Description: In this episode, the viewer will identify common security issues such as unauthorized access, file integrity issues, open ports, misconfigured security software, rogue process and services, permission issues, and data loss.

	+ Open ports \(tools: port scanners\)
