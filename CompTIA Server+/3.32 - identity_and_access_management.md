## Identity and Access Management
### Objectives:

At the end of this episode, I will be able to:

1. Identify identity and access management technologies.

Exam Objective: *3.3 - Explain important concepts pertaining to identity and access management for server administration.*

Description: In this episode, the viewer will identify techniques to govern control to resources through identity and access management such as directory services, password policies, multifactor authentication \(MFA\), single sign-on and auditing.

-----------------------------------------------------------

* What is Identity and Access Management
* Active Directory
	+ Centralized IAM solution
		- Easier user/group creation and management
	+ Single user/group database
	+ Highly scalable
	+ Apply, enforce and monitor settings
	+ SSO \(increase security with MFA\)
* Defining Password policies
	+ Requirements and enforcement
    	- Length,complexity, history, age
    	- Lockout
    	- Enforcement
    ```
    GPMC  = Comp. Setting > Win. Settings > Sec. Settings > Account Policies > Password policy
    ```
* Auditing
	+ User activity \(logins, resource access\)
	+ Group memberships
	+ Resource access
	```
    Set auditing on directory services
    (Comp. Setting > Win. Settings > Sec. Settings > Local Policies > Audit Policy > audit directory services
    
    ```
